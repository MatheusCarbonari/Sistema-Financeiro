# Web/PWA como canal inicial

O MVP usará uma aplicação web responsiva/PWA com chat e apresentações estruturadas, mantendo o núcleo financeiro independente do canal. Essa opção oferece controle sobre autenticação, privacidade e visualização de dados; Telegram poderá ser adicionado depois para interações rápidas, enquanto WhatsApp fica fora do MVP por seu custo e operação orientados à plataforma empresarial.
